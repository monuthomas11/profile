# Decisions

- Chosen stack: Next.js App Router + TypeScript + Tailwind + Motion + Resend, per PLAN.md and the repo's greenfield brief.
- Chosen platform: web.
- Chosen approach: keep all personal content in `/content` and render typed data in components so the site remains easy to replace.
- Theme behavior: system preference by default, persisted theme selection with no flash of incorrect theme.
- Contact fallback: when email delivery is not configured, the site returns a generic success message while logging the failure server-side.
- Resume behavior: placeholder PDF is shipped in `public/resume` and the `/resume` page uses print-friendly styling.
- Blog strategy: one sample MDX post is included and the index displays newest-first posts, excluding drafts in production.
